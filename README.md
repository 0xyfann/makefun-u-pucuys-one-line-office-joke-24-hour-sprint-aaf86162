# One-Line Office Joke — 24-Hour Sprint

A make.fun program/v1 entry for the competition
`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162`.

The program writes one short joke about office life to
`/output/entry.txt`. The joke:

> Our 15-minute 'quick sync' ran 47 minutes and ended with us scheduling a follow-up meeting about the meeting.

## Run

```sh
python3 -P -s main.py
```

With `MAKEFUN_OUTPUT_DIR` set, the entry is written to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Deterministic,
no network access, exits 0.
